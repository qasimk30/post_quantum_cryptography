About Kyber KEM

Kyber is a module lattice-based key encapsulation mechanism (KEM) that is one of the finalists in the NIST Post-Quantum Cryptography standardization process.

Key Features:
  • Security basis: Based on the hardness of the module learning with errors (MLWE) problem
  • Performance: Offers a good balance between key size, ciphertext size, and computational efficiency
  • Variants: Available in multiple security levels (Kyber512, Kyber768, Kyber1024)
  • Status: Selected by NIST for standardization

In this demo, we're using the Kyber512 variant from the pqcrypto Python package.
