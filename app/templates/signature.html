About Dilithium Signature
NIST Selected

Dilithium is a lattice-based digital signature scheme selected by NIST as part of the post-quantum cryptography standardization process.

Key Features:
  • Security basis: Based on the hardness of the Module Learning With Errors (MLWE) problem
  • Performance: Good balance between signature size, key size, and computational efficiency
  • Variants: Supports Dilithium2, Dilithium3, Dilithium5
  • Status: Selected by NIST for standardization

In this demo, we're using the Dilithium2 variant from the pqcrypto Python package.

Security Note:

Like all cryptographic algorithms, Dilithium's security depends on proper implementation and parameter selection. Stay updated with cryptographic guidance and best practices.
